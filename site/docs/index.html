Install

go install github.com/Blackman99/drainready/cmd/drainready@latest

Or download a single static binary (linux, macOS, windows; amd64/arm64) from Releases. It uses your normal kubeconfig, like kubectl.

Usage

drainready NODE [NODE...]          # check named nodes
drainready -l LABEL_SELECTOR       # every node matching a label
drainready --all                   # every node in the cluster
  --context NAME                   kubeconfig context
  --kubeconfig PATH
  --force                          assume drain runs with --force
  --delete-emptydir-data           assume drain runs with --delete-emptydir-data
  --server-dry-run                 confirm with server-side dry-run evictions (nothing is evicted)
  --json                           machine-readable output
  -v                               also list OK and skipped pods

Verdicts and exit codes

VerdictMeaning
OKEviction admitted now.
WAITMore pods of one PDB on this node than disruptionsAllowed. Drain completes as replacements turn ready elsewhere, if there is room.
FLAGBare pod (no controller) or emptyDir: drain refuses unless you pass --force / --delete-emptydir-data.
BLOCKEDPDB allows 0 disruptions, pod matches more than one PDB, or the server dry-run refused. Drain would retry forever.
SKIPDaemonSet, mirror/static, finished or terminating pods.

Exit code 0 ready (OK/WAIT) · 1 blocked · 3 needs a flag · 2 error.

How it works

drainready lists the pods on each node (spec.nodeName) and every PodDisruptionBudget, matches budgets to pods by selector in the same namespace, and applies the rules the Eviction API uses: status.disruptionsAllowed, multiple-PDB rejection, unhealthyPodEvictionPolicy for not-ready pods, and stale PDB status (observedGeneration). For each blocked pod it explains the cause: already-unhealthy replicas, minAvailable equal to the replica count, or maxUnavailable: 0.

The PDB status can lag reality by a few seconds. --server-dry-run sends a real eviction with dryRun=All for every pod predicted OK, which also catches admission webhooks. Nothing is evicted or cordoned.

RBAC

rules:
- apiGroups: [""]       resources: [nodes, pods]            verbs: [get, list]
- apiGroups: [policy]   resources: [poddisruptionbudgets]   verbs: [list]
# only for --server-dry-run:
- apiGroups: [""]       resources: [pods/eviction]          verbs: [create]

In upgrade scripts

drainready -l eks.amazonaws.com/nodegroup=old || { echo "fix PDBs before upgrading"; exit 1; }

Use --json to feed results to other tools. See the roadmap.
