# drainready design brief

Reference object: a container port — a quay gantry crane unloading a ship's deck stow (bay plan, stencilled container sides, lashing rods).
Metaphor: node = ship, pods = containers, drain = the crane unloading, a PDB at 0 = a container lashed to the deck that the spreader cannot lift.

- Base: light cool harbour haze #e6ecef; hull navy #13283f; container rust #b8432f / #8f3222; steel blue #3d6a9e; container bone #f1ead9; sea #6f8ea3; quay concrete #c9c3b4.
- Type: Big Shoulders Stencil Display 600/800 (container stencil) + IBM Plex Sans Condensed + IBM Plex Mono (commands only).
- Texture: corrugated container ribs (repeating vertical stripe pattern), no shadows, no glow, no gradients-as-colour.
- Rendering: flat side-elevation engineering silhouette in SVG generated by app.js.
- Layout: full-width port scene, h1 stencilled on the ship hull; sections are "bays" with navy plate numbers; install sits inside a 40ft container side; verdicts are a stack of 20ft/40ft containers stacked bottom-up.
- Motion: crane trolley/spreader unloads each pod to the quay; the lashed one jerks 3x and stays, BLOCKED is stencilled; toggling the PDB fix replays and all containers leave → READY. Verdict containers drop onto the stack on scroll. prefers-reduced-motion: final state, no motion.
- Logo: container door end (4 locking bars) hanging from a spreader. No rounded app tile.
